# Tambo branding comparison

The header and logo use a waystation motif; the footer retains the woven cords
and the stack diagram names Tambo. Each image was rendered at its SVG viewBox
size against light and dark backgrounds with animation paused at time zero.
A fresh isolated Chrome profile rendered local SVGs with HTTP(S) blocked.
